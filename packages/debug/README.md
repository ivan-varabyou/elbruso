# @elbruso/debug

Мощный инструмент для отладки React приложений с визуальной подсветкой элементов и копированием их метаданных.

## Возможности

- 🐛 **Кнопка-триггер** - зеленый жук в правом нижнем углу (только в dev режиме)
- 🎯 **Debug Mode** - активация по нажатию Ctrl, подсветка элементов с `data-file-path`
- 📋 **Копирование данных** - клик по элементу копирует его метаданные в буфер обмена
- 🎨 **Group Mode** - Ctrl+Shift для множественного выбора с цветовой подсветкой
- 💾 **LocalStorage** - состояние debug режима сохраняется между сессиями
- 🖥️ **Debug Console** - выдвижная консоль для просмотра собранных элементов

## Установка

Пакет уже интегрирован в приложение через `AppDebugProvider` в `layout.tsx`.

## Использование

### Активация Debug Mode

1. Кликните на зеленого жука 🐛 в правом нижнем углу
2. Жук станет зеленым - режим активирован
3. Зажмите **Ctrl** для активации подсветки элементов

### Копирование одного элемента

1. Активируйте debug mode (зеленый жук)
2. Зажмите **Ctrl**
3. Наведите на элемент - увидите подсказку с путем к файлу
4. Кликните - данные скопируются в буфер обмена

### Групповое копирование

1. Активируйте debug mode
2. Зажмите **Ctrl + Shift**
3. Кликайте на элементы - они будут подсвечиваться разными цветами
4. Отпустите клавиши - массив элементов скопируется в буфер обмена

### Выход из режима

- Нажмите **Esc** для выхода из активного режима
- Кликните на жука для полного отключения debug mode

## Формат данных

Каждый элемент копируется в виде объекта:

```json
{
  "filePath": "/path/to/component.tsx",
  "domPath": "div.container > section.hero:nth-child(1) > h1#title",
  "className": "text-xl font-bold text-blue-500",
  "urlPath": "/dashboard",
  "text": "Welcome to Elbruso",
  "color": "#FF6B6B"
}
```

### Поля объекта

- **filePath** - путь к файлу компонента (из `data-file-path`)
- **domPath** - CSS selector для быстрого поиска элемента в DOM
- **className** - CSS классы элемента
- **urlPath** - путь страницы без домена (pathname)
- **text** - текстовое содержимое элемента (первые 100 символов)
- **color** - цвет подсветки (для group mode)

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| **Ctrl** | Активировать подсветку элементов |
| **Ctrl + Shift** | Режим группового копирования |
| **Esc** | Выход из активного режима |
| **Click на жука** | Включить/выключить debug mode |

## Debug Console

Выдвижная консоль внизу экрана показывает все собранные элементы:

- Автоматически появляется при групповом копировании
- Показывает количество элементов
- Подсветка синтаксиса для удобного чтения
- Кнопка **Clear** для очистки списка
- Клик на заголовок для сворачивания/разворачивания

## Компоненты

### DebugProvider

Контекст для управления состоянием debug режима.

### DebugTrigger

Кнопка-жук для включения/выключения режима.

### DebugOverlay

Визуальная подсветка элементов и индикатор активного режима.

### DebugConsole

Консоль для просмотра собранных элементов.

### AppDebugProvider

Обертка, объединяющая все компоненты для использования в приложении.

## Интеграция

```tsx
import { AppDebugProvider } from '@/shared/lib/debug';

export default function RootLayout({ children }) {
  return (
    <AppDebugProvider>
      {children}
    </AppDebugProvider>
  );
}
```

## Требования

- React 18+
- Next.js (для `data-file-path` атрибутов через SWC plugin)
- Development режим (`NODE_ENV=development`)

## Примечания

- Работает только в development режиме
- Требует наличия `data-file-path` атрибутов на элементах
- Использует localStorage для сохранения состояния
- Clipboard API для копирования данных
