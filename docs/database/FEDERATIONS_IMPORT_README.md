# Импорт реестра спортивных федераций

Скрипт для импорта данных из реестра общероссийских и региональных аккредитованных спортивных федераций Минспорта РФ.

## Использование

```bash
python import_federations.py --input <CSV_FILE> --output <SQL_FILE>
```

## Что делает скрипт

1. **Парсит CSV реестр** федераций Минспорта РФ
2. **Фильтрует** федерации с истекшей аккредитацией
3. **Сопоставляет** субъекты РФ с кодами регионов из `06_regions_import.sql`
4. **Сокращает** формы собственности организаций:
   - `РЕГИОНАЛЬНАЯ ОБЩЕСТВЕННАЯ СПОРТИВНАЯ ОРГАНИЗАЦИЯ` → `РОСО`
   - `РЕГИОНАЛЬНАЯ ФИЗКУЛЬТУРНО-СПОРТИВНАЯ ОБЩЕСТВЕННАЯ ОРГАНИЗАЦИЯ` → `РФСОО`
   - и т.д.
5. **Генерирует SQL** с INSERT-ами, используя JOIN по:
   - Виду спорта (`sports.name_ru`)
   - Региону (`regions.code`)
   - Типу организации (`organization_types.code`)

- Региональных: **3079**

## Структура данных

### Входные данные (CSV)
- Наименование спортивной федерации
- Субъект Российской Федерации
- Вид спорта
- Номер-код спортивной федерации (реестровый код)
- Дата начала аккредитации
- Дата окончания аккредитации
- Номер приказа

### Выходные данные (SQL)
```sql
INSERT INTO organizations (
  level_id,        -- 4 (национальный) или 6 (региональный)
  type_id,         -- federation_national или federation_regional
  sport_id,        -- JOIN с sports по name_ru
  country_id,      -- 1 (Россия)
  region_id,       -- JOIN с regions по code
  name_ru,         -- Сокращенное название
  abbreviation_ru, -- NULL (пока не используется)
  is_active,       -- TRUE
  metadata         -- {registry_code, accreditation_end, order_number}
)
```

## Маппинг регионов

Скрипт содержит полный маппинг всех 89 субъектов РФ на коды регионов:
- Москва → `RU_MOW`
- Санкт-Петербург → `RU_SPE`
- Московская область → `RU_MOS`
- и т.д.

Для новых территорий (ДНР, ЛНР, Запорожская, Херсонская области) используются коды:
- `RU_DNR`, `RU_LNR`, `RU_ZAP`, `RU_HER`

| Полное название | Сокращение |
|----------------|------------|
| РЕГИОНАЛЬНАЯ ОБЩЕСТВЕННАЯ СПОРТИВНАЯ ОРГАНИЗАЦИЯ | РОСО |
| РЕГИОНАЛЬНАЯ ФИЗКУЛЬТУРНО-СПОРТИВНАЯ ОБЩЕСТВЕННАЯ ОРГАНИЗАЦИЯ | РФСОО |
| ОБЩЕСТВЕННАЯ ОРГАНИЗАЦИЯ | ОО |

| ОБЩЕРОССИЙСКАЯ ФИЗКУЛЬТУРНО-СПОРТИВНАЯ ОБЩЕСТВЕННАЯ ОРГАНИЗАЦИЯ | ОФСОО |
| КРАЕВАЯ РЕГИОНАЛЬНАЯ СПОРТИВНАЯ ОБЩЕСТВЕННАЯ ОРГАНИЗАЦИЯ | КРСО |
| ОБЛАСТНАЯ ОБЩЕСТВЕННАЯ ОРГАНИЗАЦИЯ | ОблОО |
| РЕСПУБЛИКАНСКАЯ ОБЩЕСТВЕННАЯ ОРГАНИЗАЦИЯ | РеспОО |

## Зависимости

Скрипт требует, чтобы в базе данных уже были импортированы:
1. `05_registry_import.sql` - виды спорта
2. `06_regions_import.sql` - регионы РФ
3. `02_core_entities.sql` - таблица `organization_types`

## Примечания

- Федерации без указания региона считаются общероссийскими
- Федерации с истекшей аккредитацией исключаются из импорта
- Реестровый код сохраняется в `metadata.registry_code`
- Дата окончания аккредитации в `metadata.accreditation_end`
