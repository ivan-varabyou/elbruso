# Система автогенерации критериев - Схема и механизм

## Концепция

Создаем **шаблон критерия** один раз, а система автоматически генерирует множество конкретных критериев на основе комбинаций параметров.

## Пример работы системы

### Шаг 1: Создаем шаблон

```
Администратор вводит:
┌──────────────────────────────────────┐
│ Название: "Призовое место в ЧР"      │
│ Категория: Достижения                │
│ Тип значения: Число                  │
│ Единица: мест                        │
│                                      │
│ Применить к:                         │
│ ☑ Пол: Мужчины, Женщины             │
│ ☑ Возраст: U14, U16, U18, U20       │
│ ☑ Дисциплина: 5х5, 3х3              │
│ ☑ Событие: ЧР, ПР                   │
│ ☑ Места: 1, 2, 3                    │
│                                      │
│ Формула веса:                        │
│ • 1 место: 5.0                       │
│ • 2 место: 3.0                       │
│ • 3 место: 2.0                       │
│                                      │
│ Шаблон названия:                     │
│ "{place} место {event} {age} ({gender}) {discipline}" │
│                                      │
│ Шаблон кода:                         │
│ "BBL_{event}_{age}_{gender}_{discipline}_PLACE_{place}" │
└──────────────────────────────────────┘
```

### Шаг 2: Система генерирует

```
Автоматически создаются критерии:
┌──────────────────────────────────────────────────────────────┐
│ BBL_CHR_U14_M_5X5_PLACE_1                                   │
│ "1 место ЧР U14 (Мужчины) 5х5" - вес: 5.0                  │
├──────────────────────────────────────────────────────────────┤
│ BBL_CHR_U14_M_5X5_PLACE_2                                   │
│ "2 место ЧР U14 (Мужчины) 5х5" - вес: 3.0                  │
├──────────────────────────────────────────────────────────────┤
│ BBL_CHR_U14_M_5X5_PLACE_3                                   │
│ "3 место ЧР U14 (Мужчины) 5х5" - вес: 2.0                  │
├──────────────────────────────────────────────────────────────┤
│ ... (еще 45 критериев для разных комбинаций)                │
└──────────────────────────────────────────────────────────────┘

ИТОГО: 2 пола × 4 возраста × 2 дисциплины × 2 события × 3 места
     = 96 критериев автоматически!
```

## Структура таблиц

### 1. Шаблон генерации

```sql
indicator_generation_template
├── id
├── name_ru                    -- "Призовые места в чемпионатах"
├── category_id
├── value_type
├── measurement_unit_id
├── sport_id
├── base_weight                -- Базовый вес
├── name_pattern               -- "{place} место {event} {age} ({gender})"
├── code_pattern               -- "BBL_{event}_{age}_{gender}_PLACE_{place}"
├── description_pattern
└── generation_config JSONB    -- Конфигурация генерации
```

### 2. Параметры генерации

```sql
template_generation_params
├── template_id
├── param_type                 -- 'gender', 'age_group', 'discipline', 'event', 'place'
├── param_values JSONB         -- [1, 2] для gender_id или ['1', '2', '3'] для мест
├── weight_formula             -- Формула расчета веса
└── is_required                -- Обязательный параметр?
```

### 3. Сгенерированные критерии

```sql
generated_indicators
├── template_id                -- Ссылка на шаблон
├── indicator_catalog_id       -- Ссылка на созданный индикатор
├── generation_params JSONB    -- Параметры, с которыми создан
└── created_at
```

## Механизм работы

### Алгоритм генерации

```
1. Получить шаблон
2. Получить все параметры шаблона
3. Создать декартово произведение всех параметров
4. Для каждой комбинации:
   a. Подставить значения в name_pattern
   b. Подставить значения в code_pattern
   c. Рассчитать вес по формуле
   d. Создать индикатор в indicator_catalog
   e. Связать с группами
   f. Записать в generated_indicators
```

### Формулы весов

```javascript
// Примеры формул
{
  "place": {
    "1": "base_weight * 1.0",
    "2": "base_weight * 0.6",
    "3": "base_weight * 0.4"
  },
  "age_group": {
    "U14": "* 0.8",
    "U16": "* 0.9",
    "U18": "* 1.0",
    "U20": "* 1.1",
    "adult": "* 1.2"
  },
  "event_level": {
    "regional": "* 0.5",
    "national": "* 1.0",
    "international": "* 1.5"
  }
}
```

## Примеры кейсов

### Кейс 1: Призовые места в чемпионатах

```
Входные данные:
- Пол: Мужчины, Женщины
- Возраст: U14, U16, U18, U20, Взрослые
- Дисциплина: 5х5, 3х3
- События: ЧР, ПР, КР
- Места: 1, 2, 3

Результат: 2 × 5 × 2 × 3 × 3 = 180 критериев
```

### Кейс 2: Участие в лигах

```
Входные данные:
- Пол: Мужчины, Женщины
- Лиги: Суперлига, Высшая лига, Первая лига
- Дисциплина: 5х5

Результат: 2 × 3 × 1 = 6 критериев
```

### Кейс 3: Судьи по категориям

```
Входные данные:
- Категория: 1-я, 2-я, 3-я, FIBA
- Дисциплина: 5х5, 3х3

Результат: 4 × 2 = 8 критериев
```

### Кейс 4: Воспитанники в сборных

```
Входные данные:
- Пол: Мужчины, Женщины
- Возраст: U14, U16, U18, U20, Взрослые
- Дисциплина: 5х5, 3х3

Результат: 2 × 5 × 2 = 20 критериев
```

## Преимущества

| Преимущество | Описание |
|--------------|----------|
| **Скорость** | 180 критериев за 1 минуту вместо часов ручной работы |
| **Консистентность** | Все критерии имеют единообразное именование |
| **Гибкость** | Легко добавить новый возраст или дисциплину |
| **Обновление** | Изменение шаблона обновляет все критерии |
| **Отслеживание** | Видно, какие критерии из какого шаблона |
