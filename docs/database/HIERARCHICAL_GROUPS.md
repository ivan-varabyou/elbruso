# Иерархическая структура групп показателей

## Обзор

Группы показателей теперь поддерживают **иерархическую структуру** через поле `parent_id`, что позволяет создавать логические подгруппы.

## Структура

```
1  - Региональная федерация
  └─ 12 - Маркетинг федерации
2  - Общие региональные показатели
3  - Спортивные объекты
4  - Сборные команды
5  - Профессиональный спорт
  └─ 13 - Маркетинг профессиональных клубов
6  - Резерв
7  - Массовый спорт (любительский)
  ├─ 14 - Школьный баскетбол
  ├─ 15 - Студенческий баскетбол
  ├─ 16 - Любительский баскетбол
  └─ 17 - Ветераны
8  - Мероприятия
9  - Судьи
10 - Тренеры
11 - Прочее
```

## Использование в UI

### Отображение дерева групп

```typescript
// Frontend пример: построение дерева
const buildTree = (groups) => {
  const map = {};
  const roots = [];
  
  groups.forEach(g => map[g.id] = {...g, children: []});
  groups.forEach(g => {
    if (g.parent_id) {
      map[g.parent_id].children.push(map[g.id]);
    } else {
      roots.push(map[g.id]);
    }
  });
  
  return roots;
};
```

### Выбор группы с учетом иерархии

## SQL запросы

### Получить все группы с иерархией

```sql
-- Рекурсивный запрос для построения дерева
WITH RECURSIVE group_tree AS (
  -- Базовый случай: группы верхнего уровня
  SELECT id, parent_id, code, name_ru, 0 as level, 
         name_ru as path
  FROM indicator_groups
  WHERE parent_id IS NULL
  
  UNION ALL
  
  -- Рекурсивный случай: дочерние группы
  SELECT g.id, g.parent_id, g.code, g.name_ru, gt.level + 1,
         gt.path || ' > ' || g.name_ru
  FROM indicator_groups g
  JOIN group_tree gt ON g.parent_id = gt.id
)
SELECT * FROM group_tree
ORDER BY path;
```

### Получить показатели группы вместе с подгруппами

```sql
-- Все показатели региональной федерации (включая маркетинг)
WITH RECURSIVE subgroups AS (
  SELECT id FROM indicator_groups WHERE id = 1
  UNION ALL
  SELECT g.id FROM indicator_groups g
  JOIN subgroups s ON g.parent_id = s.id
)
SELECT i.* FROM indicators i
WHERE i.group_id IN (SELECT id FROM subgroups);
```

## Преимущества

✅ **Логическая группировка** — маркетинг как подгруппа, а не отдельная категория  
✅ **Гибкость** — можно добавлять новые подгруппы без изменения основной структуры  
✅ **Масштабируемость** — поддержка любой глубины вложенности  
✅ **Соответствие CSV** — точное отражение структуры из Excel  
✅ **Удобный UI** — раскрывающиеся списки и древовидная навигация
