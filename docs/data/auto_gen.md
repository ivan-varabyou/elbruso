🎯 Цель агента
Создать систему, которая автоматически генерирует критерии (indicators) на основе шаблонов (indicator_templates) и базовых справочников (спорт, дисциплина, пол, возраст, диапазоны мест/результатов), а также позволяет пользователю вручную создавать и редактировать критерии.

🟦 1. Входные данные, которыми агент должен уметь пользоваться
Агент должен уметь читать данные из следующих справочников:

1.1. Вид спорта
id

code

name_ru

1.2. Дисциплины
id

sport_id

code

name_ru

1.3. Пол
id

code (M/F)

name_ru

1.4. Возрастные группы
id

code (U16, U18, AD…)

name_ru

1.5. Группы показателей
id

code

name_ru

1.6. Шаблоны критериев (indicator_templates)
Каждый шаблон содержит:

sport_id

discipline_id (nullable)

gender_id (nullable)

age_group_id (nullable)

result_type (place / medal / participation / score / boolean)

range_from

range_to

base_weight

group_id

name_pattern (например: “{place} место в {discipline_name} ({gender_name})”)

code_pattern (например: “ATH_{discipline_code}_{gender_code}PLACE{place}”)

🟦 2. Что агент должен уметь делать автоматически
2.1. Генерировать критерии по шаблону
Для каждого шаблона агент должен:

Пройти диапазон от range_from до range_to.

Подставить значения в шаблоны:

{place}

{discipline_name}

{discipline_code}

{gender_name}

{gender_code}

{age_group_code}

{sport_code}

Создать критерий (indicator) со следующими полями:

code

name_ru

group_id

sport_id

discipline_id

gender_id

age_group_id

weight = base_weight

value_type (определяется по result_type)

use_population (false по умолчанию)

description (генерируется или пустое)

Проверить, существует ли такой критерий уже:

если да → обновить (если разрешено),

если нет → создать новый.

🟦 3. Что агент должен уметь делать вручную (по запросу пользователя)
3.1. Создание критерия вручную
Пользователь может задать:

название

код

группу

вид спорта

дисциплину

пол

возраст

вес

тип значения

учёт населения

описание

Агент должен:

проверить корректность данных,

предложить код, если пользователь не указал,

создать критерий.

3.2. Редактирование критерия вручную
Пользователь может изменить:

название

вес

группу

дисциплину

пол

возраст

описание

тип значения

Агент должен:

проверить, что критерий существует,

обновить данные,

сохранить историю изменений (если включено версионирование).

3.3. Создание шаблона вручную
Пользователь может создать новый шаблон:

дисциплина = “бег 100 м”

пол = “мужчины”

возраст = “взрослые”

диапазон мест = 1–8

вес = 0.5

name_pattern = “{place} место в беге 100 м (мужчины)”

code_pattern = “ATH_100M_M_PLACE_{place}”

Агент должен:

проверить корректность,

сохранить шаблон,

предложить сразу сгенерировать критерии.

🟦 4. Логика генерации
Агент должен поддерживать следующие типы генерации:

4.1. По местам (place)
Генерирует критерии:

1 место

2 место

…

N место

4.2. По медалям (medal)
Генерирует:

золото

серебро

бронза

4.3. По участию (participation)
Генерирует:

количество участников

количество команд

количество спортсменов

4.4. По очкам (score)
Генерирует:

критерии с числовым значением

4.5. По булевым значениям (boolean)
Генерирует:

“есть/нет”

🟦 5. Требования к агенту
Агент должен:

работать строго по шаблонам,

не создавать дубликаты,

проверять корректность кодов,

автоматически подставлять названия дисциплин, пола, возраста,

поддерживать многоуровневые группы показателей,

позволять пользователю вручную вмешиваться в любой момент,

логировать все операции,

поддерживать откат изменений (undo),

поддерживать массовую генерацию (например, все дисциплины лёгкой атлетики сразу).

🟦 6. Пример задачи, которую агент должен уметь выполнить
Задача:  
Создать критерии для лёгкой атлетики, дисциплина “бег 100 метров”, отдельно для мужчин и женщин, места 1–8, вес 0.5.

Агент должен:

Найти дисциплину “100M”.

Найти gender_id = M.

Найти age_group_id = AD (если указано).

Пройти цикл 1–8.

Сгенерировать 8 критериев для мужчин.

Повторить для женщин.

Записать в базу.

Вернуть пользователю список созданных критериев.

🟦 7. Формулировка задачи для агента (готовая)
Вот текст, который можно вставить в любой AI‑агент:

ЗАДАЧА АГЕНТА “ГЕНЕРАТОР КРИТЕРИЕВ”
Создать систему автоматической генерации критериев (indicators) на основе шаблонов (indicator_templates) и справочников (спорт, дисциплина, пол, возраст, группы показателей).
Система должна:

Позволять пользователю создавать шаблоны генерации критериев.

Автоматически генерировать критерии по шаблону, включая:

подстановку дисциплины,

пола,

возраста,

диапазона мест/результатов,

веса,

кодов и названий по шаблону.

Исключать дубликаты и проверять корректность данных.

Позволять пользователю вручную создавать и редактировать критерии.

Поддерживать массовую генерацию критериев для всех дисциплин вида спорта.

Поддерживать версионирование критериев.
