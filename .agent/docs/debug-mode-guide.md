# Debug Mode - Инструкция по использованию

## 🐛 Что это?

Debug Mode - это инструмент для разработчиков, который позволяет быстро находить и копировать информацию о DOM элементах с их исходными файлами.

## 🚀 Как использовать

### 1. Активация режима

- Найдите кнопку с эмодзи жука 🐛 в правом нижнем углу (только в dev режиме)
- Кликните на неё - жук станет **зелёным** (режим включен)
- Кликните снова - жук станет **серым** (режим выключен)

### 2. Копирование одного элемента

1. Включите debug mode (зелёный жук)
2. Зажмите **Ctrl**
3. Наведите курсор на элемент - увидите подсказку с путём к файлу
4. Кликните на элемент - данные скопируются в буфер обмена

**Формат данных:**
```json
{
  "filePath": "/home/ivan/git/elbruso/apps/web/src/widgets/Hero/ui/Hero.tsx",
  "className": "text-4xl font-bold text-blue-600",
  "urlPath": "/dashboard",
  "text": "Добро пожаловать в Elbruso"
}
```

### 3. Групповое копирование

1. Включите debug mode
2. Зажмите **Ctrl + Shift**
3. Кликайте на элементы - они будут подсвечиваться разными цветами
4. Отпустите клавиши - массив элементов скопируется в буфер

**Индикатор режима:** В правом нижнем углу появится уведомление:
- 🐛 Debug Mode Active - одиночное копирование
- 🎯 Group Mode (3) - групповое копирование (число = количество элементов)

### 4. Выход из режима

- **Esc** - выход из активного режима (Ctrl/Ctrl+Shift)
- **Клик на жука** - полное отключение debug mode

## 📋 Поля объекта

| Поле | Описание |
|------|----------|
| `filePath` | Путь к файлу компонента (из `data-file-path`) |
| `className` | CSS классы элемента |
| `urlPath` | Путь страницы без домена (pathname) |
| `text` | Текстовое содержимое (первые 100 символов) |

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| **Ctrl** | Активировать подсветку элементов |
| **Ctrl + Shift** | Режим группового копирования |
| **Esc** | Выход из активного режима |

## 💡 Советы

- Debug mode работает только в development режиме
- Состояние (вкл/выкл) сохраняется в localStorage
- Элементы должны иметь атрибут `data-file-path` (добавляется автоматически через SWC plugin)
- В group mode каждый элемент подсвечивается уникальным цветом
- Данные копируются в JSON формате для удобной вставки в код

## 🔧 Технические детали

- **Компоненты:** DebugProvider, DebugTrigger, DebugOverlay
- **Пакет:** `@elbruso/debug`
- **Интеграция:** Через `AppDebugProvider` в `layout.tsx`
- **Требования:** React 18+, Next.js, NODE_ENV=development
