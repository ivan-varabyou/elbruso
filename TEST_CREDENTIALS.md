## Как войти в систему

1. Откройте http://localhost:7200
2. Нажмите "Войти" или перейдите на http://localhost:7200/login
3. Введите email и пароль из списка выше
4. Нажмите "Войти"

## Требования к паролю

При регистрации нового пользователя пароль должен содержать:
- Минимум 8 символов
- Хотя бы одну заглавную букву
- Хотя бы одну строчную букву
- Хотя бы одну цифру
- Хотя бы один специальный символ (!@#$%^&*)

## Troubleshooting

### Ошибка "Invalid credentials"
- Убедитесь, что вводите правильный email и пароль
- Проверьте, что caps lock выключен
- Попробуйте скопировать пароль из этого файла

### Ошибка "User not found"
- Пользователь может быть не создан в базе
- Попробуйте зарегистрировать нового пользователя

### API не отвечает
- Проверьте, что API запущен: http://localhost:3001/api/docs
- Проверьте логи: `docker logs elbruso-api`

## Создание нового пользователя

Вы можете зарегистрировать нового пользователя через:
- Web UI: http://localhost:7200/register
- API: POST http://localhost:3001/auth/register

Пример запроса:
```json
{
  "email": "newuser@example.com",
  "name": "New User",
  "password": "Password123!"
}
```
