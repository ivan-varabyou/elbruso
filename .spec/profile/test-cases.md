🧩 A. Тест‑кейсы: Создание таблиц
TC‑A1 — Создание пустой таблицы
Тип: Позитивный
Предусловия: Пользователь имеет право can_create_tables.

Шаги:
Открыть воркспейс.

Нажать «Создать таблицу».

Ввести название «Тестовая таблица».

Нажать «Создать».

Ожидаемый результат:
Таблица создаётся.

Открывается в центральной области.

Создана 1 версия (draft).

Количество колонок = 1 (по умолчанию).

Количество строк = 0.

TC‑A2 — Создание таблицы с пустым названием
Тип: Негативный

Шаги:
Нажать «Создать таблицу».

Оставить поле названия пустым.

Нажать «Создать».

Ожидаемый результат:
Ошибка: «Название обязательно».

Таблица не создаётся.

TC‑A3 — Создание таблицы на основе справочника (Регионы РФ)
Тип: Интеграционный

Шаги:
Нажать «Создать таблицу → На основе справочника».

Выбрать справочник «Регионы РФ».

Выбрать страну = Россия.

Нажать «Создать».

Ожидаемый результат:
Таблица создаётся.

Первая колонка = «Регион».

Количество строк = 85.

Все строки заполнены данными справочника.

🧩 B. Тест‑кейсы: Колонки
TC‑B1 — Добавление числовой колонки

Ожидаемый результат:
Колонка появляется справа.

Тип данных = number.

Ожидаемый результат:
Ошибка: «Невозможно преобразовать текст в число».

Тип не изменён.

TC‑B3 — Удаление колонки, используемой в формуле
Тип: Негативный

Шаги:
Создать колонку A.

🧩 D. Тест‑кейсы: Связи внутри воркспейса
TC‑D1 — Создание Lookup связи
Тип: Интеграционный

Шаги:
Открыть таблицу «Регионы».

Создать колонку «Население».

Открыть таблицу «Население регионов».

Создать lookup:

source_column = Регион

target_table = Население регионов

target_key = Регион

target_value = Население

Ожидаемый результат:
Колонка «Население» заполняется автоматически.

Все значения соответствуют источнику.

TC‑D2 — Lookup с отсутствующим ключом

Ожидаемый результат:
Значение lookup = пусто.
