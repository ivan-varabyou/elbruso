# 🛠 Технический стек Frontend (Elbruso) — Industrial Data Engine

## Стек технологий
| Категория | Технология | Обоснование |
| :--- | :--- | :--- |
| **Framework** | **React JS** | Стандарт для сложных SPA с богатым состоянием. |
| **Стилизация** | **Tailwind CSS** | Быстрая верстка, высокая производительность стилей. |
| **Таблицы** | **AG Grid** | Работа с миллионами строк, виртуализация, группировка, pivot-режимы. |
| **Расчеты** | **HyperFormula** | Полноценный движок Excel-формул на стороне клиента. |
| **Графики** | **D3.js** | Хирургическая точность и гибкость в визуализации аудита. |
| **Архитектура** | **FSD** | Масштабируемость и легкая заменяемость UI через `shared` слой. |
| **Упр. данными** | **TanStack Query** | Синхронизация с API, кэширование, оптимистичные обновления. |

## Список API Сущностей (Entity Mapping)
Все типы данных для фронтенда импортируются из бэкенда (`apps/api/dto` или `@elbruso/database`). Основные сущности приложения:

### 1. Доступ и Профиль
- **`User`**, **`AuthToken`**, **`ApiKey`**, **`Member`**, **`WorkspacePermission`**

### 2. Организация и Контент
- **`Workspace`**, **`WorkspaceGroup`**
- **`Page`** (Терево страниц), **`Block`** (Dashboard Widgets)

### 3. Табличные Данные и Формулы
- **`DynamicTable`**, **`TableVersion`**
- **`Cell`**, **`CellHistory`**, **`ReferenceLink`**
- **`FormulaTemplate`**, **`FormulaCache`**

### 4. Доменные Справочники (Sports Domain)
- **`Sport`**, **`Discipline`**, **`Season`**, **`Region`**, **`Organization`**, **`Federation`**
- **`Event`**, **`Indicator`**, **`IndicatorGroup`**

## Архитектурные принципы FSD
- **Shared Layer:** Атомарные компоненты без бизнес-логики. Быстрая смена дизайна всей системы.
- **Entities Layer:** Чистые модели данных, типы которых тянутся с бэкенда.
- **Features Layer:** Реализация пользовательских действий (EditCell, AuditTable, InviteMember).
- **Widgets Layer:** Композиция фич в крупные блоки (Sidebar, AI-Chat, GridEditor).

## Генерация типов
Для исключения ошибок типизации используется прямой импорт типов из пакета `@elbruso/database/src/types.ts` и DTO бэкенда. **Ручное создание интерфейсов, дублирующих бэкенд, запрещено.**
